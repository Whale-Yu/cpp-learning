- 符号常量：满足标识符的硬性要求下，如若使用英文字母，应全部大写
- 变量：满足标识符的硬性要求下，如若使用英文字母，不应全部大写（可大小写组合或纯小写）

# 通用规范：见名知意、下划线命名法、小驼峰法、大驼峰法

## 见名知意
标识符的命名应道有具体的含义

## 下划线命名法
当命名标识符的时候，为了满足见名知意要求，可以使用多个单词或数字的组合
为了区别每个单词，可以使用下划线区分
```
std::string student_name = "小明";
std::string teacher_name = "小明";
int itheima_stu_id = 1;
int itcast_stu_id = 1;
```

## 小驼峰法
也是为了区分单词：
- 大小写首字母进行区分
- 简短的单词可以全大写
```
std::string studentName = "小明";
std::string teacherName = "小明";
int itheimaStuID = 1;
int itcastStuID = 1;
```

## 大驼峰法
相比于小驼峰法，每个单词首字母都是大写
```
std::string StudentName = "小明";
std::string TeacherName = "小明";
int ItheimaStuID = 1;
int ItcastStuID = 1;
```

## 总结
- 见名知意：任何场景
- 下划分命名法：变量
- 小驼峰法：变量、函数
- 大驼峰法：类
备注：没有统一要求，根据企业或组织的代码规范即可
